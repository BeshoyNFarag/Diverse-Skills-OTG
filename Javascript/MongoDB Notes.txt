UPDATING DOCUMENTS:

db.COLLECTION_NAME.updateOne({_id: Object + id} ,{$set: {KEY: NEW_VALUE, ANOTHER_KEY: ANOTHER_NEW_VALUE}}) 

db.COLLECTION_NAME.updateOne({ATTRIBUTE: KEY} ,{$set: {KEY: NEW_VALUE, ANOTHER_KEY: ANOTHER_NEW_VALUE}}) --> this here will match everything that holds the exact KEY for that ATTRIBUTE and set something inside to new value

db.COLLECTION_NAME.updateOne({_id: Object + id} ,{$inc: {KEY: INCREMENT_AMOUNT_AS_NUMBER}})  --> here we increment the amount inside the key


db.COLLECTION_NAME.updateOne({_id: Object + id} ,{$pull: {KEY: A_VALUE_INSIDE_ARRAY_TO_DELETE}})  --> here we delete a value inside an array 

db.COLLECTION_NAME.updateOne({_id: Object + id} ,{$push: {KEY: A_VALUE_INSIDE_ARRAY_TO_ADD}})  --> here we append a value inside an array

we can use $each inside the key followed by an array of elements and each of those elements will be pushed to the array
