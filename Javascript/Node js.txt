Create a simple web server:

first and most importantly we need to import a package called http
require('http') returns an object
http.createServer((request,response)=> ) we can pass a callback function that will be executed each time a new request arrives to the server
const http = require('http');
//this one here handles the incoming requests
const server = http.createServer((req, res) => {
    console.log('Server has started')
});

//maps the server into a port and an ip
server.listen(3000,'127.0.0.1' ,() => {
    console.log('Server is listening on port 3000');
});

the server .listen starts the HTTP server and makes it listen for incoming requests on a specific port.
on a specific ip address
once the server has started it is not automatically terminated because of the event loop.
